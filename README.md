# 粵語讀音工具（中大「粵語審音配詞字庫」）

輸入一個繁體中文詞語（例如 **魯迪烏斯**），工具會逐個字去香港中文大學
[粵語審音配詞字庫 (Lexi-can)](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-can/)
查粵拼，下載每個字嘅真人讀音，合併成一個 WAV 檔，再用瀏覽器打開一個網頁播放。

## 需要甚麼
- Windows + **Python 3.8 或以上**（3.12 / 3.13 都得）。安裝 Python 時保留預設的「tcl/tk and IDLE」選項（視窗版要用）。
- **唔使 `pip install` 任何嘢**，唔使 ffmpeg —— 全部只用 Python 標準庫。
- 要上網。

## 檔案
| 檔案 | 用途 |
|---|---|
| `cantonese_gui.pyw` | **視窗版**，雙擊就開（唔會彈黑色視窗） |
| `cantonese.py` | 核心程式；亦可以喺命令列用 |
| `cache\` | 自動建立：已下載嘅讀音同聲音檔（第二次查同一個字就唔使再上網） |
| `output\` | 自動建立：`詞語.wav` 同 `詞語.html` |

兩個 `.py/.pyw` 檔要放喺**同一個資料夾**。

## 點用
### 視窗版
1. 雙擊 `cantonese_gui.pyw`
2. 喺輸入格打詞語，例如 `瑞傑路德`
3. 按 **Enter** 或者「查詢讀音」掣
4. 視窗會顯示每個字嘅粵拼（例如 `瑞 seoi6 傑 git6 路 lou6 德 dak1`），然後自動打開瀏覽器播放
5. 想循環聽，勾「循環播放」（網頁播放器亦有同一個勾選）
6. 想聽得更順、音量更齊，按「更順／音量正常」（再開一次會還原）。呢個模式用交叉淡化接字，並將音量正規化
7. 視窗唔會關，可以繼續查下一個詞

### 命令列版
```
python cantonese.py              （互動模式：打詞語，按 Enter；直接按 Enter 離開）
python cantonese.py 魯迪烏斯      （只查一個詞）
python cantonese.py --no-browser 魯迪烏斯 --gap 0.15
python cantonese.py --loop --smooth 魯迪烏斯
```

### 多音字
有啲字有幾個讀音（例如「行」：hang4 / hong4 / haang4…）。工具會揀字庫入面**詞例最多**嗰個讀音，
並會列出其他讀音。想指定讀音，就喺字後面加方括號：

```
銀行[hong4]
```

## 網頁內容
- 大字顯示個詞，每個字下面有粵拼
- 「播放全詞」播放器（會嘗試自動播放）
- 每個字下面有 ▶ 小掣，可以逐個字聽

## 限制
- 只認得 **Big5 繁體字**；簡體字（例如「鲁」）同部份罕見字會略過並顯示提示。
- 每個字係**單獨讀音**拼埋一齊，冇變調，聽落會似逐個字讀。
- 多音字只係「估」最常用讀音，未必啱個詞語，有需要請用 `字[拼音]` 指定。
- 中大網站連唔到時，會自動改用 Internet Archive (web.archive.org) 嘅備份；但備份唔齊（例如「烏」wu1 嘅聲音冇備份），
  而且有啲字（例如「德」「烏」「人」）因為備份網址唔分大小寫而查唔到。正常喺香港上網直接連中大網站就冇呢個問題。
- 有啲瀏覽器唔准網頁自動播放聲音，按一下「播放全詞」就得。
- 讀音及聲音版權屬香港中文大學，只供個人學習用。
